
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da forca em Python para praticar manipulação de strings, listas, seleção aleatória, laços de repetição e condicionais.

## 📝 Tarefas

### 🛠️ Implementar o ciclo de palpites

#### Descrição

Complete o código inicial para escolher uma palavra secreta e permitir que o jogador tente adivinhá-la, uma letra por vez.

#### Requisitos

O programa concluído deve:

- Selecionar aleatoriamente uma palavra da lista fornecida no código inicial.
- Mostrar cada letra ainda não descoberta como `_` e atualizar o progresso após cada palpite correto.
- Aceitar palpites de uma letra, sem diferenciar letras maiúsculas de minúsculas.
- Registrar as letras já tentadas e não descontar uma tentativa por um palpite repetido.
- Contar os palpites incorretos e permitir no máximo 6 erros.

### 🛠️ Encerrar a partida e informar o resultado

#### Descrição

Finalize o jogo quando o jogador descobrir a palavra ou atingir o limite de erros e apresente o resultado da partida.

#### Requisitos

O programa concluído deve:

- Encerrar a partida quando todas as letras da palavra forem descobertas ou quando ocorrerem 6 erros.
- Exibir uma mensagem de vitória quando a palavra for descoberta.
- Exibir uma mensagem de derrota e revelar a palavra secreta quando o limite de erros for atingido.
